# boAt — Find Your Sound (UI/UX Concept Redesign)

A responsive front-end concept for a boAt-inspired audio shopping experience. Built with plain HTML, CSS and JavaScript so it can be opened locally or deployed using GitHub Pages.

## Included
- Responsive landing page for desktop and mobile
- Category navigation and product filters
- Product sorting (price low-to-high / high-to-low)
- Product search
- Add-to-cart interactions and slide-out cart drawer
- Custom SVG product illustrations stored locally in `assets/`

## Run locally
1. Download and extract the folder.
2. Open `index.html` in a browser. For best results, use VS Code with the Live Server extension.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload all files and folders while keeping the same structure.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for the Pages URL to appear.

## UX direction
The concept emphasizes:
- A clearer first-screen value proposition and one primary CTA
- Three easy-to-scan product categories
- Product cards with price, rating, category and a clear add-to-cart action
- Filters and sorting to reduce product discovery effort
- Persistent cart access and a visible subtotal
